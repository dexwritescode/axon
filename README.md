# Axon

![Build](https://github.com/dexwritescode/axon/actions/workflows/build.yml/badge.svg)
![Test](https://github.com/dexwritescode/axon/actions/workflows/test.yml/badge.svg)

Axon is a terminal-based AI coding agent. You give it a goal in natural language; it plans, reads and edits files, runs shell commands, and iterates until the work is done — all visible in real time in the TUI.

It connects to any OpenAI-compatible backend (Neurons, Ollama, LM Studio, vLLM, or a hosted endpoint). Nothing leaves the machine unless you point Axon at a remote host.
